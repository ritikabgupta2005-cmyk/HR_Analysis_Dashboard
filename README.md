# HR Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data using Power BI. The dashboard helps visualize employee data and understand workforce trends to support better HR decision-making.

## 🛠️ Tools Used

* **Power BI** – Dashboard creation and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures

## 📊 Key Features

* Employee data analysis
* Workforce trend visualization
* Department-wise employee analysis
* HR metrics and KPI tracking
* Interactive charts and filters

## 🎯 Project Objective

The objective of this project is to transform HR data into meaningful insights through interactive dashboards and visualizations.


## 💡 Key Learnings

* Data cleaning and transformation
* Creating interactive dashboards in Power BI
* Using visualizations to analyze data
* Presenting data-driven insights
